# Лабораторная работа 5: Telegram-бот курсов валют

Бот получает и показывает текущие курсы валют в формате online.

- Основной источник данных: [РБК "Курсы ЦБ РФ"](http://stock.rbc.ru/demo/cb.0/intraday/)
- Если сайт РБК временно недоступен, используется резервный источник ЦБ РФ.

## Функционал

- `/start` - запуск и краткая справка
- `/list` - список доступных валют
- `/rate USD` - курс выбранной валюты
- можно отправить просто код валюты, например `EUR`

Реализован расширенный вариант задания (вариант 2): выбор любой валюты из списка.

## Запуск

1. Установить зависимости:
   - `pip install -r requirements.txt`
2. Создать Telegram-бота через [@BotFather](https://t.me/BotFather) и получить токен.
3. Задать переменную окружения:
   - PowerShell: `$env:TELEGRAM_BOT_TOKEN="ваш_токен"`
4. Запустить:
   - `python bot.py`
