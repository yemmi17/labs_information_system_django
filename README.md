# Справочник сотрудников фирмы

Учебное Django-приложение для хранения персональных данных работников фирмы с разными уровнями доступа.

## Роли

- Директор: полный доступ на просмотр, добавление, изменение и удаление.
- Заместитель директора: просмотр и редактирование без добавления и удаления.
- Секретарь: полный просмотр без права изменения.
- Гость: доступ без пароля только к ФИО, должности и рабочему телефону.

## Демо-аккаунты

- `director / director123`
- `deputy / deputy123`
- `secretary / secretary123`

## Запуск

```bash
py manage.py migrate
py manage.py runserver
```

После миграций откройте главную страницу и выберите вход по роли.
