# Запуск бота

## 1. Окружение Python

Рекомендуется отдельное виртуальное окружение (в репозитории уже может быть `venv/` — можно использовать его или создать новое).

```powershell
pip install -r requirements.txt
```

## 2. Токен Telegram

1. В Telegram откройте [@BotFather](https://t.me/BotFather), создайте бота и скопируйте **токен**.
2. В корне проекта создайте файл `.env` (шаблон — `.env.example`):

```env
BOT_TOKEN=ваш_токен_от_BotFather
```

## 3. Старт

Из корня репозитория (чтобы пакеты `bot` и `mini_case` были на `PYTHONPATH`):

```powershell
python -m bot.main
```

В логах должно появиться подключение к Telegram; в клиенте найдите своего бота и нажмите **Start**.

## 4. Быстрая проверка сценария

1. `/start` → **Собрать цепочку**.
2. Выберите, например, F₃ = **√x**, F₂ = **e^x**, F₁ = **1/x**.
3. Введите `x = 4` — ожидается цепочка без ошибки (промежуточные значения положительные).
4. Пересоберите цепочку так, чтобы на каком-то шаге нарушить ОДЗ (например, F₃ = **√x**, **x = -1**) — должно прийти сообщение с **номером шага** и пояснением.

## 5. Ошибка подключения к `api.telegram.org` (Windows: WinError 121)

Если при запуске появляется трассировка с текстом вроде:

`Cannot connect to host api.telegram.org:443`  
`OSError: [WinError 121] Превышен таймаут семафора`  
`TelegramNetworkError: ... ClientConnectorError`

это **не ошибка кода бота**, а **отсутствие сетевого доступа** к серверам Telegram (блокировка провайдером, корпоративный файрвол, нестабильный маршрут и т.п.).

**Что сделать:**

1. **Проверить доступ с той же машины**, например в PowerShell:
   `Test-NetConnection api.telegram.org -Port 443`  
   Если `TcpTestSucceeded : False` — до API вы не достучитесь, пока не смените сеть или не используете обход.

2. **Включить VPN** (или системный туннель), при котором `api.telegram.org:443` начинает открываться, и снова запустить `python -m bot.main`.

3. **Прокси для Bot API** (если VPN даёт только локальный SOCKS, без полного туннеля): в `.env` задайте переменную **`TELEGRAM_PROXY`**, например:
   `TELEGRAM_PROXY=socks5://127.0.0.1:1080`  
   (порт и тип возьмите из настроек вашего VPN/прокси-клиента). Установите зависимости: `pip install -r requirements.txt` — в списке есть **`aiohttp-socks`**, он нужен для прокси.

4. При редких обрывах можно увеличить таймаут: **`TELEGRAM_HTTP_TIMEOUT=90`** (секунды).
