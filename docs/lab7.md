# Лабораторная работа №7

## Тема

Создание ИС на основе типовых решений. Изменение информационных объектов и баз данных.

## Реализация в Django

Вместо 1С/Access используется Django-приложение, где справочник контрагентов реализован моделью `Counterparty`.

Соответствие учебным объектам:

- справочник контрагентов: модель `Counterparty`;
- реквизит ИНН: поле `inn`;
- интерактивная запись элемента: форма `CounterpartyForm`;
- обработка проверки дублей: view `counterparty_mark_duplicates`;
- кнопка "Проверить ИНН": ссылка на `counterparty_check_inn`.

## Проверки

- ИНН обязателен.
- ИНН должен состоять из 10 или 12 цифр.
- При поиске дублей показываются совпадения и подстрочные вхождения.
- Повторные записи можно пометить на удаление, первая запись остается основной.

## Проверка результата

```bash
py manage.py migrate
py manage.py test
py manage.py runserver
```

После запуска открыть `/counterparties/`.
