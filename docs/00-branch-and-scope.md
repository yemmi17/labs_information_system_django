## Что вошло в реализацию (scope)

Сделано **только то, что в типовом ТЗ набрано обычным (чёрным) текстом**, без отдельного десктопного приложения:

1. Модель композиции **y = F₁(F₂(F₃(x)))** из трёх выбираемых функций из набора **{√x, 1/x, e^x}**.
2. Корректный порядок вложенных вычислений: сначала **F₃(x)**, затем **F₂(·)**, затем **F₁(·)**.
3. Обработка ошибок области определения:
   - для **√x** — если на входе шага отрицательное число;
   - для **1/x** — если на входе шага ноль.
4. Интерфейс в виде **Telegram-бота**: выбор функций и действий выполняется **инлайн-кнопками** (аналог «кнопок интерфейса» без отдельного GUI).

## Что намеренно не реализовано

- Отдельное окно/desktop (по требованию заказчика).
- Пункты, которые в скане ТЗ выделены **синим** (отдельная «визуальная» схема блоков, генерация **VBA**) — в объём текущей постановки **не входят**.
