# Лабораторная работа №8

## Тема

Создание ИС на основе типовых решений. Добавление печатных форм.

## Реализация в Django

Выбран вариант 1: печатная форма для справочника "Материалы".

Соответствие учебным объектам:

- справочник материалов: модель `Material`;
- поля отчета: `code`, `name`, `accounting_account`;
- печатная форма: шаблон `material_print_report.html`;
- кнопка печати: `window.print()`;
- условное форматирование: CSS-классы `quantity-above`, `quantity-below`, `quantity-normal`, `quantity-multiple`.

## Правила подсветки

- количество выше 100: красная строка;
- количество ниже 10: синяя строка;
- количество между порогами: зеленая строка;
- количество кратно 5: желтая строка.

## Проверка результата

```bash
py manage.py migrate
py manage.py test
py manage.py runserver
```

После запуска открыть `/materials/`, затем перейти в "Печатная форма".
