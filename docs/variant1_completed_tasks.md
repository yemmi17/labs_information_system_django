# Лабораторная работа: подсистема вывода информации (вариант 1)

## Цель работы

Изучить и применить принципы создания интерфейсов подсистемы вывода информации для автоматизированного рабочего места специалиста.

## Что было реализовано

Реализация выполнена в виде отдельного раздела Django-приложения:

- URL: `/sales/monitor/`
- Шаблон интерфейса: `sales/templates/sales/parameter_monitor.html`
- Обработчик: `sales/views.py` (`parameter_monitor_view`)
- Маршрут: `sales/urls.py`
- Ссылка на раздел добавлена на главную страницу: `sales/templates/sales/home.html`

## Выполнение требований задания

### 1) Отображение текущего и предыдущих значений (N1 = 2..10)

- На форме задается `N1` (`history_size`) с ограничением от 2 до 10.
- Показываются:
  - текущее значение;
  - список предыдущих значений;
  - текущая группа значений для анализа.
- История значений сохраняется в сессии пользователя (`request.session`), чтобы данные не терялись между запросами.

### 2) Отображение данных в виде графика

- Строится линейный график текущей группы данных.
- График генерируется на сервере через `matplotlib` и выводится на страницу в формате Base64 PNG.

### 3) Выборка из текущих данных

Реализованы все требуемые режимы отбора:

- значения больше заданной границы (`gt`);
- значения меньше заданной границы (`lt`);
- значения, кратные заданному числу (`multiple`).

### 4) График выборочных значений + среднее (красная линия)

- Для выборки строится отдельный линейный график.
- На графике проводится красная пунктирная линия среднего значения выборки.
- Среднее также выводится числом в блоке результатов.

### 5) Диаграмма выборочных значений

- Дополнительно строится столбчатая диаграмма (bar chart) по выборочным значениям.

### 6) Предупреждение при изменении текущего значения более N2 = 5..40%

- На форме задается порог `N2` (`percent_threshold`) с ограничением от 5 до 40.
- Считается процент изменения между текущим и предыдущим значением.
- Если порог превышен:
  - показывается визуальное предупреждение;
  - воспроизводится звуковой сигнал в браузере (Web Audio API).

### 7) Тревога при выходе из допустимой области

- Пользователь задает минимальную и максимальную допустимые границы.
- Если текущее значение выходит за диапазон:
  - показывается визуальная тревога;
  - воспроизводится усиленный звуковой сигнал.

## Соблюдение принципов интерфейса АРМ

В интерфейсе учтены ключевые требования из теоретической части:

- читаемый шрифт и контрастные элементы статусов;
- логичное расположение блоков (ввод параметров, числовые данные, визуализация);
- явная система предупреждений и тревог;
- быстрый сценарий работы оператора (все параметры и результаты на одном экране);
- визуальная поддержка анализа динамики и ретроспективы по графикам.

## Техническая реализация

- Backend: Python + Django
- Математика/обработка: `numpy`
- Графики: `matplotlib`
- Frontend: HTML + CSS + JavaScript (звуковые сигналы через Web Audio API)

## Обновления зависимостей

В `requirements.txt` добавлены:

- `matplotlib`
- `numpy`

## Как проверить работу

1. Установить зависимости: `pip install -r requirements.txt`
2. Запустить сервер: `python manage.py runserver`
3. Открыть страницу: `http://127.0.0.1:8000/sales/monitor/`
4. Ввести текущее значение и параметры N1/N2, границы и тип выборки.
5. Проверить:
   - построение графиков;
   - отбор значений;
   - расчет среднего;
   - появление предупреждения/тревоги и звуковой индикации.
