# Лабораторная работа №9

## Тема

Создание ИС на основе типовых решений. Добавление новых информационных объектов.

## Реализация в Django

Для учета пробега автотранспорта добавлены новые информационные объекты:

- `Car`: справочник автомобилей;
- `Driver`: справочник водителей;
- `DriverCar`: связь водитель-автомобиль;
- `Waybill`: документ "Путевой лист".

## Вычисления

- пробег = конечный километраж - начальный километраж;
- расход топлива = пробег * норма расхода автомобиля;
- статистика по водителям суммирует пробег;
- статистика по автомобилям суммирует расход топлива.

## Диаграммы

На странице `/transport/` отображаются две диаграммы:

- пробег по водителям с красной линией среднего значения;
- расход топлива по автомобилям с красной линией среднего значения.

Диаграммы построены средствами HTML/CSS без внешних зависимостей.

## Проверка результата

```bash
py manage.py migrate
py manage.py test

```

После запуска открыть `/transport/`.
